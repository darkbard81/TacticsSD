# 실행과 입력

`cd /home/deck/Documents/TacticsSD` 후 `npm run game` → **http://127.0.0.1:5173/game/** (기본 브라우저 자동 열기, 실패 시 URL 직접 접속). 5173 점유 시 명확한 오류로 종료한다. 기존 서버를 종료하지 않고 `npm run game -- --port 5174`로 다른 로컬 포트를 지정할 수 있다. 루트 `/`의 게임 시작 링크도 사용 가능. 기존 `/tools/characterRig/` 제작 도구는 그대로 유지한다. `npm run build`는 게임과 도구를 함께 빌드한다.

최소 지원/필수 UI 검증: **1024×768 CSSpx, DPR2**. 이때 게임 보드의 전체 화면 캔버스 backing은 **2048×1536**이다. 런타임은 window.innerWidth/innerHeight/devicePixelRatio를 매 프레임 비교하고 실제 변경에 맞춰 backing을 다시 만든다. DPR 상한은 없으며 브라우저에 DPR2를 강제하지 않는다. 메뉴·캔버스·마우스 좌표는 CSS 픽셀 기준이다.

|의미 action|기본 키|브라우저 표준 게임패드|
|---|---|---|
|선택/타일 이동|방향키|D-pad12–15 / 왼쪽 스틱|
|확인|Enter / Space|0 (일반적인 남쪽 버튼)|
|취소/뒤로|Escape|1 (동쪽 버튼)|
|일시정지|P|9 (Start)|
|활성 유닛 초점 또는 대상 순환|Q/E|4/5 (범퍼)|
|등각↔Top view|V|3 (북쪽 버튼)|
|카메라 이동|I/J/K/L|오른쪽 스틱|
|확대/축소|+/−|7/6 (트리거)|
|카메라 복원|R|11 (R3)|

전투의 방향키는 논리 타일 X/Y축을 따른다. 등각에서는 보드의 두 대각축, Top view에서는 화면 상하좌우가 된다. 좌표·선택·턴 상태는 전환 중에도 유지된다. Top view 전환에 캐릭터가 눕지 않으며 어느 시점에서도 캐릭터 투과 마스크를 사용하지 않는다.

진행: 새 원정 → 거점 → 부대 편성 → (장비/보급품) → 출전 → 대화 선택 → 전투. E/Q로 RT가0인 활성 유닛을 선택한다. 이동1회, 공격/필살/마법/아이템 중 일반 행동1회, 별도 활성기술 결의1회를 원하는 순서로 실행한다. 이동만 했다면 되돌리기가 가능하고 행동 후에는 취소할 수 없다. 대상은 방향키/범퍼로 순환한다. AT 종료에서 방향키로 종료 방향을 정하고 확인한다. P → 현재 AT 종료도 같은 방향 선택으로 연결된다. 적의 개별 AT는 자동 실행된다.

설정에서 각 키/디지털 패드 버튼을 바꿀 수 있다. 중복은 기존 동작과 교환한다. Escape 또는 고정 패드 Back(8)로 입력 대기를 취소한다. 키 입력대기는 현재 매핑된 취소 버튼으로도 탈출한다. Tab은 포커스 이동용으로 예약되어 매핑할 수 없으며, Space를 명시적으로 다른 동작에 지정하면 확인의 별칭으로 중복 실행하지 않는다. 기본값 복원과 localStorage 저장/복원이 있다. 버튼 이름은 SDL이라고 주장하지 않으며 browser standard 숫자 인덱스다. 비표준 컨트롤러는 직접 버튼 지정이 필요하다. 스틱 deadzone0.30, 최초 repeat340ms/이후100ms, 확인/취소는 누름 edge만 사용한다. 창 비활성화 또는 컨트롤러 분리 시 전투 일시정지. 키보드로 복구하거나 재연결 후 계속할 수 있다. 재연결·버튼 재매핑 직후에는 패드 버튼과 스틱이 중립으로 돌아와야 새 패드 동작을 받으며, 기다리는 동안에도 키보드는 사용할 수 있다.

저장 범위: 캠페인 해방 거점/보상/편성/장비/클래스레벨/SP/배운 기술/지원스킬 및 별도 입력 설정/시점. 전투 도중 저장은 **출전 전 체크포인트**이며 타이틀에서 이어할 때 안내한다. 브라우저 저장을 사용할 수 없으면 현재 플레이를 유지하면서 오류를 알린다. 새 원정을 시작해도 기존 저장은 다음 저장/출전 전까지 남는다.

기술·수련에서 직업 기술을 SP8로 배우고 장착하며, 지원 스킬1개를 선택한다. 첫 거점 승리 시 출전 대원 SP12와 출전 직업 공유레벨+1(자체 규칙). 편성의 출전 순서 변경은 초기 배치/첫 AT 순서를 바꾼다. 전투 가방은 치유의잎·마력의물·용기의물을 선택하고 기존 대상 확인으로 사용한다. 장비→리그·파츠에서 도구 v2 JSON과 모든 참조 이미지를 함께 가져오면 재시작 후에도 유지된다. 파일 선택은 브라우저/운영체제 대화상자이며 물리 패드만으로 OS 파일선택까지 조작 가능한지는 미검증이다.


상점:월드→보급소→구매/판매→분류→품목→수량→확인창→거래확정. 취소는변경없음. 패드/키보드확인이동시에들어와도한번만거래하며확인+취소동시에는취소가우선. 거래확인중패드해제/창비활성화시확인창을닫는다. 구매장비는보급소대원선택→장착으로적용가능. 원문도감은분류/이전·다음/10쪽이동을패드로조작한다.
