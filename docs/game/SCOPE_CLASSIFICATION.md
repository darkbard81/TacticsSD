# 남은 항목의 요구 근거 재분류 · 2026-10-04

이 문서는 이전 REMEDIATION.md의 “원작과 다른 것 전부가 원요구 미완료”로 읽힐 수 있는 판정을 정정한다. 부모 대화의 원 사용자 메시지를 직접 역조회했다. 사용자의 **추천 결정 허용**과 **docs 최대 활용**을 함께 적용한다. 기능을 임의로 제외한 것이 아니라, 원래 지시와 추가 범위를 구분한다.

부모 지시도 “전체 OV모드/전체 PSP복제의 포괄승인으로 확대하지 말라”고 명시했다. 따라서 원작 설명서에 존재한다는 사실만으로 새 대형 시스템을 필수 요구로 만들지 않는다.

## C · 환경에서 확인할 수 없는 검증

실물패드 버튼/스틱 감각, Steam Input/SDL·비표준장치, 실제 GPU/디스플레이 성능, 운영체제 파일선택의 물리패드 조작. Chromium/Gamepad API mock과 실제viewport/DPR 테스트로 대체 검증한 부분을 구별한다. 구현권한 문제가 아니라 해당 실물환경 부재다.
