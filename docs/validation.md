## 원본 한계와 구현 문제의 구분

현재 엘프는 완성된 스탠디 그림입니다. 팔·몸통이 붙어 있고 흰색 테두리가 외곽 전체를 감쌉니다. 초기 사각형은 완전한 의미론적 분할이 아니어서 팔 일부에 몸통 픽셀이 포함되고, 파츠 이동 시 접합부에 틈이나 절단선이 보입니다. 앞면/후면이 정확히 동일한 실루엣도 아닙니다. 입력에서 가려진 부분은 복원하지 않습니다. 외부에서 정리한 투명 파츠를 교체 입력하는 방식으로 해결합니다.

분리 가능한 테스트 원본에서는 Rest 위치와 pivot 변경 후 픽셀 복원이 확인됩니다. 분수 픽셀 영역은 GPU 선형 샘플링에 따라 가장자리의 미세한 알파 차이를 만들 수 있어 초기 자동 영역은 정수 픽셀 경계를 사용합니다. 방향 보정은 실제 측면 생성이 아니므로 정면 원화가 자연스러운 3/4 원화로 변환된다고 보장하지 않습니다.

실제 물리 터치 기기 및 Safari/Firefox 실행은 이 기록에 포함하지 않습니다. 모바일 검증은 Chromium의 화면 폭/DPR 에뮬레이션입니다. 상기 테스트는 모델/저장 계약과 Chromium 사용자 흐름을 증명하며, 임의의 원본 그림에서 분할 품질을 보장하는 테스트가 아닙니다.
