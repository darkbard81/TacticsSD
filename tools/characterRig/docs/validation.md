## 리뷰 반영

[리뷰 댓글](https://github.com/darkbard81/TacticsSD/issues/1#issuecomment-5866111406)의 pivot/socket 계층 제안을 적용했습니다. 기본 리그와 새 리그는 몸통에 머리·팔·다리를 연결합니다. `attachment.socket`은 부모 이미지 좌표, `restTransform`은 연결 후 보정입니다. 파츠 ID는 `legL / legR`로 변경했습니다. 신규 에셋 규격은 투명 RGBA, Front/Back 독립 6파츠(총 12영역)를 권장합니다.

후속 결정으로 개발 단계의 JSON 하위 호환성을 제거했습니다. 과거 스키마·마이그레이션·v1 fixture 및 호환 테스트를 삭제했으며 현재 v2만 허용합니다. 구조 변경 시 이전 파일을 폐기하고 기본 리그를 재생성합니다. 현재 부모는 몸통 또는 지면만 지원하고 임의의 다관절 체인과 IK는 지원하지 않습니다. 숨김·단독 보기는 그림에만 적용하므로 부모의 변형은 계속 상속됩니다.

## 입력과 검증의 한계

제공 시트는 흰 배경 JPG입니다. 원본을 보관하고 내장 image_gen 편집으로 투명 PNG 파생본을 만들었습니다. 흰 의상과 테두리 보존을 요청했으나 생성 기반 편집이므로 원본과 픽셀 동일성을 보장하지 않습니다. 에디터 자체에 자동 배경 제거 기능을 추가한 것은 아닙니다.

원본에 후면 전용 팔이 없어 두 팔을 앞·뒤에서 공용으로 사용합니다. 파츠 사이의 흰 외곽선은 남아 있으며, 큰 모션에서는 관절 접합부가 보일 수 있습니다. 등각은 2D 반전과 파츠 보정으로, 새로운 측면 원화를 생성하지 않습니다. 외부에서 정리한 파츠 이미지를 교체할 수 있습니다.

일반 완성 스탠디는 사각형 영역에 인접 부위가 포함되어 움직일 때 절단·틈이 생길 수 있습니다. 테스트는 저장·좌표·렌더링 계약과 Chromium 사용자 흐름을 검증하며 임의 원본의 자동 분할 품질을 보장하지 않습니다. 실제 물리 터치 기기, Safari/Firefox는 검증 범위에 포함하지 않습니다.
