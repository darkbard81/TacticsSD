## 입력과 검증의 한계

제공 시트는 흰 배경 JPG입니다. 원본을 보관하고 내장 image_gen 편집으로 투명 PNG 파생본을 만들었습니다. 흰 의상과 테두리 보존을 요청했으나 생성 기반 편집이므로 원본과 픽셀 동일성을 보장하지 않습니다. 에디터 자체에 자동 배경 제거 기능을 추가한 것은 아닙니다.

원본에 후면 전용 팔이 없어 두 팔을 앞·뒤에서 공용으로 사용합니다. 파츠 사이의 흰 외곽선은 남아 있으며, 큰 모션에서는 관절 접합부가 보일 수 있습니다. 등각은 2D 반전과 파츠 보정으로, 새로운 측면 원화를 생성하지 않습니다. 외부에서 정리한 파츠 이미지를 교체할 수 있습니다.

일반 완성 스탠디는 사각형 영역에 인접 부위가 포함되어 움직일 때 절단·틈이 생길 수 있습니다. 테스트는 저장·좌표·렌더링 계약과 Chromium 사용자 흐름을 검증하며 임의 원본의 자동 분할 품질을 보장하지 않습니다. 실제 물리 터치 기기, Safari/Firefox는 검증 범위에 포함하지 않습니다.
