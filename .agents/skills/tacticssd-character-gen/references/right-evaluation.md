# Right 생성 후 평가와 재생성

Front Right는 **Front Base 한 장**, Back Right는 **Back Base 한 장**만 생성 참조로 사용한다. Left는 비교 평가용이다. 실패 후보도 재생성 참조로 사용하지 않는다. Right 프롬프트는 `character_gen.py prompt front-right` 또는 `back-right`의 원문 그대로이다.

## 관찰 기준

같은 방향의 Base·Left·Right 후보를 `view_image`로 직접 확인한다. 파일명이나 프롬프트의 의도를 보고 실제 자세를 추정하지 않는다. 관찰한 왼손·오른손·왼발·오른발의 상태를 각각 `전진`, `후진`, `판별 불가`로 기록하고, 겹침·팔꿈치 굽힘·원근·발바닥 노출 등 근거를 짧게 적는다. 손 위치를 발 위치로 대신 판정하거나, 이미지 전체의 픽셀 차이가 있다는 이유만으로 반대 자세라고 판정하지 않는다.

모든 좌우는 캐릭터의 해부학적 기준이다. 정면에서 왼쪽 팔다리는 화면 오른쪽, 오른쪽 팔다리는 화면 왼쪽이다. 후면에서는 해부학적 좌우와 화면 좌우가 같다. 전진은 캐릭터가 바라보는 방향이다. 정면 전진은 관찰자 쪽, 후면 전진은 관찰자로부터 멀어지는 쪽이다.

| 팔다리 | 검증된 Left | 통과할 Right |
|---|---|---|
| 왼손 | 전진 | 후진 |
| 오른손 | 후진 | 전진 |
| 왼발 | 후진 | 전진 |
| 오른발 | 전진 | 후진 |

Front Right의 전진 오른손은 화면 왼쪽에서 관찰자 쪽으로 나오고, 후진 왼손은 화면 오른쪽에서 뒤로 간다. 전진 왼발은 화면 오른쪽에서 앞으로 내딛고, 후진 오른발은 화면 왼쪽에서 뒤로 간다.

Back Right의 전진 오른손은 화면 오른쪽에서 관찰자로부터 멀어지며 엉덩이 옆에 일부 가려질 수 있다. 후진 왼손은 화면 왼쪽에서 관찰자 쪽으로 나오고 보인다. 전진 왼발은 화면 왼쪽에서 더 멀리 놓여 상대적으로 위에 보이고, 후진 오른발은 화면 오른쪽에서 뒤꿈치를 들고 밀어내며 밑창이 드러날 수 있다. 화면 높이만으로 결론 내리지 않고 관절·겹침·발 방향도 함께 확인한다.

Base와 비교해 동일 캐릭터, 신체 비율과 머리의 원래 방향이 유지되는지도 확인한다. 완전한 정면/후면, 전신·1:1·투명 배경, 무기 없음, 양손 주먹도 통과해야 한다. 이 판정은 시각적 관찰이며 Pillow 파일 형식 검사는 보행을 판별하지 않는다.

## 반복 절차

1. 현재 Right 후보를 임시 이름으로 보관하고 파일 형식·알파를 검사한다. 기존 최종 Right를 실패 후보로 덮어쓰지 않는다.
2. Left의 네 팔다리가 표의 Left 조건인지 확인한다. Left가 틀렸거나 판별 불가이면 비교 기준이 성립하지 않으므로 Right를 평가·재생성하기 전에 Left 단계의 공통 재생성 규칙으로 기준을 복구한다. 이번 실행에서 이미 사용한 Left 호출 횟수도 포함한다. Left가 상한 내에 통과하지 못하거나 필요한 참조가 없으면 멈추고 구체적인 이유를 보고한다.
3. Right의 네 팔다리 관찰 결과를 표와 대조한다. **네 팔다리 모두 반대 자세**이고 캐릭터·방향·전신·주먹·파일 조건도 맞을 때만 통과시킨다.
4. Right가 Left와 같은 보행이면 `Left와 동일`로 실패 처리한다. 일부만 반대이거나 불분명하거나 다른 필수 조건이 틀려도 실패 처리한다. 실패 항목과 근거를 기록한다.
5. 실패하면 **같은 Base 한 장 + 동일한 Right 프롬프트 + transparent_background: true**로 새 후보를 생성하고 1–4를 다시 실행한다. 프롬프트를 강화하거나 실패 이유를 새 문장으로 덧붙이지 않는다. Left 또는 실패 후보를 도구의 참조 목록에 추가하지 않는다.
6. 방향별 최초 생성 1회 + 재생성 최대 3회, 총 최대 4회 호출을 실행한다. 도구 호출 오류·결과 미반환도 같은 횟수에 포함하며, 실패 유형이 바뀌어도 초기화하지 않는다. 이미지가 반환되지 않으면 오류를 기록한 뒤 상한 내에서 5의 동일 조건으로 재시도한다. 총 4회 모두 실패하면 해당 단계에서 멈추고 최초·재생성 횟수와 마지막 오류 또는 평가 근거를 보고한다. 부적합한 후보를 최종 Right로 저장하거나 다음 단계로 넘어가지 않는다.
7. 통과 후보만 `<Class>_Front_Right.png` 또는 `<Class>_Back_Right.png`로 복사한다. Base·Left를 수정하지 않는다. 최종 보고에 방향별 시도 횟수와 네 팔다리의 Left/Right 비교 표를 포함한다.

재생성은 이 절차를 실행하는 Codex가 내장 imagegen 호출을 반복해 수행한다. `character_gen.py`가 imagegen을 호출하거나 시각적 평가를 자동 수행하는 것은 아니다.
